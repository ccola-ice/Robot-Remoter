# 触摸主机回归测试

在仓库根目录的 Windows PowerShell 中运行（需要 MinGW GCC）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\7_Test\host\run_touch_tests.ps1
```

从 EIDE 工程目录运行时改为 `..\7_Test\host\run_touch_tests.ps1`。
可使用 `-Compiler 'D:\path\to\gcc.exe'` 指定编译器。

测试直接编译生产 `gt9xx.c` 和 `palette.c`，模拟寄存器总线与帧缓冲，不访问实际外设。
覆盖方向映射、分辨率缩放、完整帧握手、延迟就绪与漏中断、五条硬件记录换序、
无效/重复 ID、部分读取与确认失败、超时和时钟回绕、单指工具栏归属及画布边界、
全部笔刷/橡皮裁剪、双地址探测、初始化失败禁用，以及四角校准各方向和回绕模型。

用户确认只需单指后，FIELD-SINGLE-8 删除了多笔迹/按大小融合逻辑，测试同步移除这些旧行为断言。
额外硬件点仍完整校验，但不另画一笔；主指消失后，未关联的其他指不能抢占当前手势。

- `test_single_field_path()` 使用本次斜线、竖线日志的原始坐标，确认停滞片段不直接落笔，
  出口到达后补齐线段，竖画只保留原片段的一条轨迹。该斜线用例在 FIELD-SEAM-7 下失败。
- `test_single_lifecycle()` 检查四个斜向往返的逐列连续性和直线几何误差、快速无重叠交接、
  冻结原片段仍存在时采用有效出口、暂存线段在抬起/错误/超时/退出后不泄漏到下一次手势，
  以及区域内竖线换 ID 的位置对齐与区域外绝对坐标恢复。
- 串口测试编译生产转换头文件与 FatFs `cc936.c`，检查 GBK 转 UTF-8、ASCII、CRLF 和非法字节恢复。

现场日志不含每一采样帧，重放中的时间间隔为明确模拟，不宣称还原实际采样时序。
这些测试不加入固件目标，不能验证电气时序、玻璃通道配置、断区真实位置精度或上板流畅度。
