# 遥控器页面重设计

2026-09-21。按用户选择，将 **LimeRC 的页面视觉布局**与 **XRC 的遥控信息组织**结合，实际修改现有 EIDE 工程中的 LCD 页面。

## 参考依据与落地

LimeRC 的依据是归档中的 `DOC/LimeRC V3使用手册.pdf` 第 5、8 页，以及 `Lime_HeadBar.c`、`Lime_LittleAppFirmware.c`、`Lime_App_Settings.c`。XRC 的依据是两版 `XUAN/desk.c`、`XUAN/channel.c`、`XUAN/statusbar.c` 和 `USER/rc_main.c` 的实际绘图代码；未将 LVGL 示例截图当成 XRC 产品页面。

| 参考思路 | 本机 800×480 页面 |
|---|---|
| Lime 大图标、独立标题、轻量状态栏 | 三分类图标首页，分类内 3×2 功能网格，32 px 顶栏显示本机电池、无线 ACK、时间 |
| Lime 浅色圆角列表、选中行和右侧箭头 | 参数、无线和文件页；浅蓝选中，编辑态独立提示，保留保存结果 |
| Lime 摇杆十字图 | 控制页左右摇杆、中心刻线和位置圆点；中央显示机器人速度、电压和航向 |
| XRC 通道表与中点行程条 | RAW 两列输入，OUTPUT 并列原始值、校准值、反向和正负通道条；右侧显示实际发送帧 |
| XRC 状态与数据分区 | 输出允许状态、本机传感器、机器人遥测分区；无数据时明确显示等待或占位 |

配色使用浅灰背景、白色面板、深色文字和蓝色焦点；负向通道条使用绿色。图标由本项目的线、圆和矩形接口独立绘制。没有导入参考项目的图标、背景、字体或 GUI 框架。附带资料中的操作说明仅作为参考内容。

## 操作和数据语义

- 首页用 LEFT/RIGHT 选择分类，OK 打开，BACK 返回上级；分类记住各自的焦点。
- Channel Monitor 中 LEFT/RIGHT/OK 切换 RAW 与 OUTPUT，BACK 返回控制菜单。
- Parameters 与 Wireless 中 LEFT/RIGHT 选择，OK 编辑或运行，BACK 取消当前编辑或返回；参数沿用显式保存及读回校验。
- 通道监视只读，不使能控制。首页的输出状态为锁定；机器人控制仍受 DCH1、自检、电池、输入新鲜度及无线条件约束。
- 顶栏 RF ACK 仅表示无线硬件应答。机器人速度、电压和位置只接受机器人遥测，未接入回传时显示 `--` / `NO ROBOT TELEMETRY`。
- RAW 中 A09 为摇杆按压采样，BAT 为本机电池 ADC；二者单列，不画成比例摇杆轴。本机 IMU/GPS 不作为机器人遥测。

## 实现位置与资源

- [`1_App/gui_theme.h`](../1_App/gui_theme.h)：统一颜色、有限宽文字、圆角面板、原创几何图标、中心双向条。
- [`1_App/gui.c`](../1_App/gui.c)：页面构图、状态栏和差量更新。
- [`1_App/menu.c`](../1_App/menu.c)：首页加入周期状态刷新，沿用原事件队列和页面状态机。
- [`7_Test/host`](../7_Test/host)：真实绘图、输入滤波、菜单和运行边界回归。

没有新增目标平台堆分配或整页缓冲。换页继续使用既有外部 SRAM 合成后提交；实时数值只更新局部区域，首页数据节拍 250 ms、输出文字 100 ms、机器人文字 250 ms、IMU 100 ms。界面沿用内置英文字体，文件名保留现有中英文绘制支持。

本次页面修改不改变 RC v1 编码；RT v1 的编解码和接收端接入边界见[通信协议设计](通信协议设计.md)。
