# 全页面字体清晰度优化

本轮保持原有文字大小、字格宽度、行距和内容区布局，改善字形、笔画和颜色。右上角改为单行日期时间。

## 显示变化

- 中文改用统一的无衬线字形，英文和数字采用等宽字形。16、20、32、48 px 分别从轮廓字体生成，不再把一套 32 px 点阵缩小或放大。
- 使用四级灰度处理笔画边缘，细线和复杂汉字不再依靠 2×2 像素取并集。32 px 加粗使用独立字重，避免旧的像素膨胀造成转角和字腔拥挤。
- 辅助文字、蓝色数值及状态文字加深，保留原配色关系。深色顶栏中的未校时提示单独使用亮色。
- 主菜单、通道监视、机器人控制、系统信息、IMU、GPS、参数、无线、日历、文件浏览、开机和硬件测试共用原生字形入口。EEPROM 页通过现有诊断文字入口一并覆盖。

| 文字样式 | 保持的中文字格 | 保持的英文/数字字格 |
|---|---|---|
| 小号说明、状态栏 | 16×16 | 8×16 |
| 诊断计数条 | 20×20 | 10×20 |
| 标题、常规数值、设置列表 | 32×32 | 16×32 |
| 大号仪表值 | 48×48 | 24×48 |

顶栏现在统一在同一基线上显示，例如 `2026-09-21 12:34:56 周一`。未校时时追加“未校时”；最长为 31 个半宽字格，显示至 x=784，保留右边距。电池和无线状态向左调整，为日期时间留出完整一行。日期、星期和校时状态改变时仍会刷新，即使秒数没有变化。

## 字库和兼容性

界面内置 370 个 GB2312 字符及 95 个可打印 ASCII 字符的各字号字模。界面文字现在随 MCU 固件一起烧录，无需额外更新 SPI Flash 字库。动态文件名中不在内置字集的汉字继续使用原外置字库；特殊缩放尺寸保留旧绘制回退。

中文来源为 Noto Sans SC，英文为 DejaVu Sans Mono；随仓库保存字模生成脚本、完整授权文本及原始字体 SHA，原始 TTF 和主机生成工具不进入固件。[字库生成与授权说明](../5_ModuleDrivers/fonts/README-ui-font.md)

中文字形优先从内置只读表取得，原缓存仅在外置回退时使用。原生绘制仍通过四行缓冲与 `LCD_BlitRGB565` 完成，字符背景不透明覆盖，并沿用 SRAM 局部提交。没有增加第二张整屏缓冲。

## 验证结果

- 当前 EIDE 的 100 个源文件完整编译通过，新增代码无编译警告；原有 12 个第三方/旧代码警告保留。
- 最终 ROM 为 842.13 KiB，RAM 为 82.17 KiB，均在 STM32F407ZG 的当前链接配置范围内。原生字模和索引合计 524,400 B 只读数据，渲染暂存新增 384 B RAM。
- 字库测试覆盖源字符串、全部 16 位字符索引、各字号和粗体、四级灰度、行尾 padding、统一基线及生成结果复现。
- 原生渲染测试检查 16/20/32/48 px 尺寸、ASCII 半宽、RGB565 混色、空格清除、屏幕边界、反色、换行、中英混排及缺字回退。
- LCD 实际绘制回归检查 80 次页面切换、48 组设置状态转换及 144 组日历状态转换。诊断页和文件名改用生产文字绘制函数，中文 UTF-8 与 CP936 文件名的最终像素一致；稳定页面不重复写屏。
- 保留外置中文字库/旧粗体回退测试；模拟量 GUI 和运行时控制安全回归通过。
