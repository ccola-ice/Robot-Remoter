# 菜单刷新、中文与状态含义

2026-09-21，根据实板快速按键时的闪烁反馈修复。

## 快速切换为何闪烁

原来只有切换页面时调用 `LCD_BeginPage()`。同一页换焦点或编辑数值仅设置 `page_dirty`，绘图直接写 LCD，面板会看到“擦背景→画图标→画文字”的中间过程。原主机测试检查最终像素，没有证明焦点更新期间屏幕不被擦写。

现在焦点、设置列表、动态值和时钟均先在现有 SRAM 页面上完成绘制，再提交变化区域。驱动用 16×16 像素块记录变化并合并提交，没有分配第二张整屏缓冲。母菜单和功能网格的选项内部保持白底，焦点只更新蓝色边框与页码，减少连续按键的传输量。同一轮事件队列只提交最终选择。常规刷新关闭同步串口计时输出，需要板测时可显式开启 `LCD_PAGE_TIMING_LOG`。

主机实际总线计数：母菜单焦点最多提交 29,696 像素（整屏 7.7%），功能网格 24,064 像素，参数选中行 81,920 像素；绘制完成前没有 LCD 像素写入，提交结果与整页重绘一致。方向切换和旧 BMP 直接写屏入口会使 SRAM 镜像失效，防止随后回放旧画面。

原理图显示接口未见 TE 信号接到 MCU，现有驱动也未同步 TE。上述修复消除软件中间擦写并缩短传输，不能把主机逐像素通过等同于实板绝对没有扫描撕裂。跨页面仍需要整页传输；无可用 SRAM 时保留直接绘制回退。

## 为什么原来很多值是 UNAVAILABLE

参数结构沿用了旧遥控器的预留字段，当前程序没有消费其中的接收端电池告警、油门手型、模型类型、微调步长、按键音、开机图、闹钟及时间、油门检查/保护和 PPM 开关。原菜单把这些字段也列为设置项，再统一显示 `UNAVAILABLE`，容易让人误以为读取失败。

现在菜单只列 40 项：7 个实际全局项、前 6 路通道各 5 个校准项，以及保存、重新载入、恢复默认 3 个操作。预留字段和没有使用的后两组通道从菜单隐藏，Flash 数据格式保持兼容。固件版本为只读。

同时保持校准下限＜中点＜上限，避免编辑到相等值后在保存校验中被恢复默认；按 BACK 取消、保存失败回滚及改回原值后的未保存提示均有回归验证。

## 中文显示

菜单标题、功能名、主要状态、参数标签与按键提示改为中文；NRF、ADC、GPS、DCH1 和数值单位等缩写保留。中文沿用已有外部 Flash 的 GB2312 32×32 字库，新增 16/32/48 px 混排支持，字段截断不会拆开双字节字符。缓存最多 64 字，避免换焦点反复读取字库；读取失败或空白/擦除字形显示缺字框，不复用旧字形。

[页面预览](ui-preview/index.html)使用生产 GUI、LCD 绘制代码和 ASCII 字体。主机无法读取板上 Flash 字库，中文预览使用模拟字库；实际字形以板上已烧录字库为准。模拟字库没有进入固件。

## NRF 开关与运动控制

| 显示/操作 | 实际含义 |
|---|---|
| 无线设置右侧“无线发射：开启” | 当前编辑草稿；还需要执行“应用并保存” |
| 应用并保存 | 保存校验通过后应用 NRF 设置；回读不一致会明确提示 |
| 左侧“当前生效设置” | 实际模块设置的读回结果 |
| 无线发射启用后 | 前台以约 20 ms 为目标周期，在驱动空闲且无 I/O 错误时尝试发送 RC v1 |
| 首页/设置页中的发送 | 发送禁止运动的安全帧；不代表可以驱动机器人 |
| 无线硬件回执 | NRF 芯片 ACK，不能证明机器人应用已执行命令 |
| 主页“运动控制：已禁止” | 本机未允许发送运动命令；不是机器人回传的锁定状态 |

原 `ROBOT OUTPUT / LOCKED` 已改为“运动控制 / 已禁止”。只有进入机器人控制页并满足自检、输入、电池和无线条件，松开 DCH1 且摇杆回中 500 ms 后，再按住 DCH1，才允许运动输出。释放按键或退出控制页会撤销本机使能；接收端的停车行为仍取决于其对 RC v1 安全规则的实现。

NRF 页编辑时 OK/BACK 都是结束当前草稿编辑，页面已按此显示；参数页的 BACK 则会取消当前参数修改。

## 验证

新增验证涵盖合成阶段零 LCD 写入、连续焦点改变的最终像素、局部提交量、队列事件合并、直接绘制后镜像失效、无 SRAM 回退及横竖屏边界。保留原页面转换、通道滤波、遥测失效与控制隔离回归。

中文专项覆盖混排宽度、不拆字、16/32/48 px 字形、缓存与淘汰、Flash 失败和缺字恢复。参数专项覆盖 40 项目录、可编辑项取消、16,200 次校准边界变化及保存成功/失败。

AC5 完整构建 100 个源文件通过，ROM 323.79 KiB、RAM 81.42 KiB；12 条既有告警，无新增告警。菜单、LCD、模拟通道、运行边界、控制保护、按键、中文和参数菜单回归通过，原参数存储的 4,231 个断电边界测试也通过。
